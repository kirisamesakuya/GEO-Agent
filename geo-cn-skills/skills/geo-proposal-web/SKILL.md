# geo-proposal-web

GEO 服务提案：套餐、周期、验收标准、30/60/90 天路线图摘要。

## taskType

`geo_proposal`

## Inputs

`brandName`, `geoReport` or audit summary, `industry`, `competitors`

## Workflow

1. 基于诊断缺口生成服务包 P0/P1
2. 路线图摘要 `data.roadmap`（30/60/90）
3. `artifacts` proposal markdown

## Output

`geoWebOutput.v1`. Single JSON only.
