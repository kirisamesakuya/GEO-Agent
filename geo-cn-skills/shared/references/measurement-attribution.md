# GEO 效果监测与归因规则

## 指标定义

| 指标 | 计算方式 |
|---|---|
| 品牌出现率 | 提及品牌或别名的成功样本数 / 成功样本数 |
| 候选率 | 品牌被列为候选方案的样本数 / 成功样本数 |
| 推荐率 | 品牌被明确推荐且给出正向理由的样本数 / 成功样本数 |
| 官网引用率 | 引用品牌官网的样本数 / 成功样本数 |
| 有效引用率 | 引用确实支持相邻断言的数量 / 已审核引用数量 |
| 描述准确率 | 与品牌事实库一致的断言数 / 已审核品牌断言数 |
| 竞品压制度 | 品牌推荐率 - 主要竞品推荐率 |
| 答案稳定性 | 同 Prompt 重复采样在结论、候选、排序、引用源上的一致率 |
| 证据完整率 | 同时具备原文、时间、平台和截图/URL 的样本数 / 成功样本数 |

失败、登录阻断、验证码和页面不可达不得计为未命中，必须从业务分母中剥离并单列成功采样率。

## 最小实验设计

1. T0 至少执行两轮基线采样，避免单次回答波动。
2. 每个核心意图至少包含核心问法、长尾问法、对照问法。
3. 发布后按 T+7、T+14、T+30 使用同一 Prompt 版本复测。
4. 修改 Prompt、平台入口、地区或登录状态后必须创建新实验版本，不与旧版本直接拼接。
5. 样本少于 30 个成功回答时，报告必须标记“小样本，仅作方向观察”。

## 归因置信度

| 级别 | 条件 |
|---|---|
| observed_change | 仅观察到前后差异 |
| possible_association | 有基线和复测，方向与发布时间一致，但缺少充分对照 |
| medium_confidence_attribution | 有处理/对照 Prompt、多个时间点和混杂因素记录 |
| high_confidence_attribution | 样本充分、多个平台趋势一致、对照稳定、无明显外部事件解释 |

禁止使用“发布文章后一定提升”“该文章导致排名增长”等无对照因果表述。
