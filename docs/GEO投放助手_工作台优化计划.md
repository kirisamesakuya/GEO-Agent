# GEO 投放助手 · 工作台优化计划

日期：2026-06-04  
关联文档：[GEO投放助手_发布端信息架构优化方案.md](./GEO投放助手_发布端信息架构优化方案.md)

## 1. 背景与问题

### 1.1 当前页面结构（自上而下）

| 顺序 | 区块 | 约占首屏 | 问题 |
|------|------|----------|------|
| 1 | 品牌范围条 `BrandScopeBar` | 顶栏 | 合理，保留 |
| 2 | 标题「工作台 / GEO 增长交付数据看板」 | 一行 | 合理，可压缩 |
| 3 | **快捷入口**（5 宫格） | **大块** | 与侧栏能力重复 |
| 4 | **待办提醒**（列表卡片） | **大块** | 挤占数据区首屏 |
| 5 | **数据驾驶舱**（KPI + 图表） | 需滚动才完整可见 | **应为首屏主体** |

用户反馈：**数据才是最优先的**；左侧已有「生成 GEO 文章」与「新建任务建议」，工作台内 **快捷入口** 无必要继续占位。

### 1.2 与侧栏的职责重叠

| 能力 | 侧栏已有 | 工作台快捷入口 |
|------|----------|----------------|
| 一键创作 | 「生成 GEO 文章」主按钮 + 新建任务建议弹窗 | 一键创作 |
| 收录 | 收录排名 | 收录查询 |
| 发布 | 内容发布（计划内） | 内容发布 |
| 接单 | 接单投放 | 接单投放 |
| 品牌 | 品牌管理 | 品牌管理 |

结论：工作台不应再承担 **导航分发**，应专注 **当前品牌的可观测结果与异常信号**。

---

## 2. 优化目标

1. **首屏即数据**：进入工作台后，默认看到 KPI + 核心趋势图，无需滚动越过快捷入口/待办。
2. **去掉快捷入口区块**：导航统一由侧栏 + 新建任务建议承担。
3. **待办降级为「异常条」**：保留跳转能力，不占独立大卡片；与数据驾驶舱形成「指标 + 待处理」一体感知。
4. **与信息架构文档对齐**：工作台定位仍为「总览、待办、关键指标」，但 **指标优先、待办次之**。

```

├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤
│ ┌─ 数据驾驶舱 ────────────────────────────────────────────┐ │
```

**删除**：整块「快捷入口」`section`（`WorkbenchView` 中 `SHORTCUTS` 网格）。

## 4. 分项方案

### 4.1 快捷入口 — 移除（P0，已落地）

| 项 | 说明 |
|----|------|
| 前端 | 已删除 `WorkbenchView` 快捷入口宫格；空态不再放「生成文章/收录」等重复按钮 |
| 跳转替代 | KPI / 图表空态按钮 / 待办条 已带 `onNavigate`，足够承接「从数据发现问题 → 去处理」 |
| 侧栏 | 维持「生成 GEO 文章」「快速发起任务」；不在工作台复制 |

### 4.2 待办提醒 — 收拢为「待处理条」（P0）

**现状**：独立 `geo-card`，每条待办一行，与 KPI 同级权重。

**目标**：

- 有 P0 时：标题行右侧或 KPI 上方展示 **琥珀色细条**（最多展示 2 条，其余「+N」展开）。
- 无待办：不占位（不占高度）。
- 点击条目：仍 `onNavigate(targetView)`，行为不变。
- 可选：点击「展开」展开完整列表（抽屉或折叠面板），替代当前常驻大卡片。

**数据**：继续用 `/api/publisher/dashboard` 的 `todos`，无需改 API；仅改展示组件。

建议组件：`WorkbenchAlertStrip`（新建于 `workbench/` 或内联于 `WorkbenchDashboard` 顶部）。

### 4.3 数据驾驶舱 — 上移并强化首屏（P0）

| 项 | 说明 |
|----|------|
| 顺序 | `BrandScopeBar` → 精简标题 →（待处理条）→ `WorkbenchDashboard` |
| 标题 | 副标题可改为「{brandName} · 数据驾驶舱」，与模块内「数据驾驶舱」合并考虑，避免重复文案 |
| 空态 | 无品牌数据时仍整页空态；有数据时 **禁止** 在数据上方再插大块非数据内容 |

**P1 增强（可选）**：

- KPI 单元格展示环比（需 API 增加 `previousPeriod` 或前端缓存上次值）。
- 「平台命中率 / 品牌提及率」环图旁增加「上次 GEO 分析时间」链接。

### 4.4 页头元信息（P1）

- 展示 `samplingNote` 或「最近采样 N 条」于驾驶舱内已有；页头可增加 **上次刷新时间**（`load()` 完成时更新），增强「看板」可信度。

### 4.5 多品牌场景（P2）

- 顶栏 `BrandScopeBar` 已支持切换品牌；工作台仅展示 **当前选中品牌** 的数据（与现逻辑一致）。
- 若未来需要「组织级总览」，单独增加「全部品牌」聚合页，**不**在工作台堆快捷入口。

## 6. 验收标准

1. 打开工作台（1080p 视口）：**无需滚动** 即可看到 KPI 条 + 趋势图顶部区域。
2. 页面中 **不再出现**「快捷入口」五宫格。
3. 有待办时：总高度 **≤ 当前待办卡片的 40%**，且可一键跳转处理页。
4. 侧栏「生成 GEO 文章 / 新建任务建议」仍为创建类任务唯一主入口（工作台不重复）。
5. `npm run lint` 通过；`/api/publisher/dashboard` 契约不变。

## 8. 不建议做的事

- **不要** 在工作台再加一排「最近任务」（侧栏已去掉，避免回流）。
- **不要** 用快捷入口替代侧栏瘦身（会加剧「到处都能点」的困惑）。
- **不要** 把待办做成与 KPI 同尺寸的第二个「驾驶舱」（待办是动作入口，不是分析主体）。
