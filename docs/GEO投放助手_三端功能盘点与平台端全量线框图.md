# GEO 投放助手：三端功能盘点与平台端全量线框图

版本：v0.1  
日期：2026-06-05  
范围：发布端、接单端、平台端  
目标：先把现有前台功能梳理清楚，再补齐平台端现有页面与缺失页面的低保真线框图。

---

## 1. 总体结论

当前发布端和接单端已经形成了较完整的业务闭环，但平台端仍偏“单文件后台表格集合”，缺少对发布账号、内容发布、排名监控、接单方资源、风控工单、消息通知等关键运营对象的独立页面。

平台端首页也不应继续做文字列表型后台，而应改为“运营驾驶舱”：首屏看业务态势、风险、履约、Agent 健康和资金异常；明细表格下沉到二级页面。

## 2. 发布端现有功能盘点
