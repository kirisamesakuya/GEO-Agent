设计原则

商务 / 专业 / 数据优先 / shadcn-lar 管理端方向

稳重克制

低饱和度配色，清晰层级，不过度装饰。

数据优先

突出数字、趋势、表格和 B2B 看板效率。

一致性

统一间距、圆角、字体和组件状态。

可读性

对比度充足，信息密度适中，适合长时间使用。

Usage Notes

  • Typography hierarchy 优先使用 文字/* 样式，不随意引入新的灰度色。
  • Borders、table separators、modal separators、sidebar lines 优先使用 分割线/* 样式。
  • Page surfaces、selected states、panel fills、empty-state blocks 优先使用 背景/* 样式。
  • 不要从该 Figma color set 中引入新的 brand color；它只定义 neutral color styles。
