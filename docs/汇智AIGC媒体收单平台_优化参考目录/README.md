## 4. 审阅 Agent 检查清单

审阅其他 Agent 产出时，请至少检查以下事项：

### 4.1 结构检查

1. 页面是否采用了规定的参考模板
2. 布局是否符合巨量星图 / 蒲公英的页面分工
3. 是否补齐了必需模块

### 4.2 视觉检查

1. 工作台页是否过度红粉化
2. 入驻页是否过度后台化
3. 卡片、按钮、标签、筛选器是否统一

### 4.3 体验检查

1. 是否有空态、加载态、错误态
2. 是否有清晰下一步动作
3. 是否仍然像“表单 Demo”，而不是产品页面

### 4.4 业务检查

1. 报价页是否清楚表达 P0/F/G
2. 比价页是否只向发布方展示 G
3. 财务页是否有摘要、筛选、表格、分页完整链路

### 4.5 工程检查

1. 是否优先使用 Mock / ViewModel
2. 是否避免直接渲染数据库字段
3. 是否把业务判断散落在组件模板里

---

## 5. 给其他 AI 的统一执行口径

如果你是接手开发的 AI，请遵守：

1. 先看迭代方案，再看设计规范，再看页面级映射
2. 先定页面结构，再接数据
3. 先用 Mock 把页面做完整，再接接口
4. 不要用“后端还没好”当作页面粗糙的理由
5. 不要脱离参考模板自由发挥成另一种产品风格

---

## 6. 最终结论

这 3 份文档构成当前项目优化工作的统一参考目录：

1. 方案文档解决“做什么、优先级是什么”
2. 设计规范解决“整体应该长什么样”
3. 页面映射清单解决“具体页面怎么落”

后续所有 Agent 都应默认以这 3 份文档为共同标准，而不是各自基于当前页面自由演化。
