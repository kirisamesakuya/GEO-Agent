## 2. 本迭代原则

1. **不新增**一级导航、项目实体表、项目概览页、右侧 360px 助手面板。
2. **只优化**现有弹窗的文案、排序、说明与跳转准确性。
3. **弱关联**已有 `GeoContentProject`：从「生成 GEO 文章」进入时可选带入当前品牌，不做强制项目创建。
4. 与 [工作台优化计划](./GEO投放助手_工作台优化计划.md) 一致：工作台不承担重复导航，快速发起以侧栏按钮为唯一主入口。

## 3. 轻量优化项（建议范围）

### P0 — 文案与认知对齐

| 项 | 现状问题 | 建议 |
|----|----------|------|
| 弹窗标题 | 「快速发起项目」易让人以为会建项目档案 | 副标题写清：**选择起点，进入对应功能**（非创建项目档案） |
| 四项描述 | 与落地页 IA 不完全一致 | 对齐最新命名：文章结果、任务交付、排名监控、品牌词库 |
| 发布任务 | 描述仍偏「任务包」 | 改为：发布文章到接单端 / 提交网页需求 |

### P1 — 入口顺序与可达性

| 项 | 建议 |
|----|------|
| 排序 | 按用户主路径：**GEO 分析 → 生成 GEO 文章 → 发布任务 → 关键词挖掘**（诊断先于生产） |
| 品牌 | 弹窗展示 `effectiveBrand`；`__all__` 时提示先选品牌（与 `BrandScopeBar` 一致） |
| 关闭后记忆 | 可选 `localStorage` 记录上次选择的起点，下次高亮（不做强制默认跳转） |

### P2 — 与文章结果弱联动（可选）

| 项 | 说明 |
|----|------|
| 从弹窗进「生成 GEO 文章」 | 生成完成后仍进 `content_library` / `GeoProjectLibraryShell`，不弹「创建投放项目」 |
| 新建分组 | 保留文章结果内「新建分组」，不在快速发起弹窗重复 |

### 明确不做（归入远期重设计文档）

- 投放项目 CRUD、项目阶段机、项目内任务包时间线  
- 侧栏「投放项目」列表页  
- 弹窗内 GEO 诊断 + 计划生成一体化表单

## 5. 验收标准

1. 用户点击「快速发起项目」后，**不出现**项目创建表单，仍为 4 卡片选择。
2. 四项跳转目标与侧栏/Header 标题一致，无死链。
3. 弹窗说明能让非技术用户理解：**这是快捷入口，不是新建项目档案**。
4. 与 `GEO投放助手_快速发起项目项目化重设计_*.md` 中「投放项目」能力 **零耦合**。
